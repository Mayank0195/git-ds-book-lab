# Contributing to churn-model

1. Create a branch from `main`: `feature/<short-name>` or `fix/<short-name>`.
2. Keep changes small; one topic per pull request.
3. Run `pytest` before pushing. New features need tests.
4. Do not commit data, models, notebooks with outputs, or secrets
   (see `.gitignore`).
5. Write commit messages in the imperative mood ("Add tenure bucket feature"),
   with a body that explains why when the reason is not obvious.
6. Open a pull request against `main` and request a review.
